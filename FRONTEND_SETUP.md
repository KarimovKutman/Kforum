# Kforum: веб-интерфейс и запуск

## Что добавлено

- Thymeleaf-интерфейс: главная страница, список категорий, страница категории, тема с комментариями, поиск.
- Вход по email и паролю, регистрация с серверной валидацией и уведомления после действий.
- Создание тем и комментариев для авторизованных пользователей.
- Админ-панель для создания и удаления категорий.
- Разделение ролей `USER` и `ADMIN`: `/admin/**` и `/api/admin/**` требуют `ROLE_ADMIN`; публикация тем и комментариев требует входа.
- Веб-вход использует сессию Spring Security; имеющийся JWT-фильтр оставлен для API.
- Миграция Flyway `V2__align_schema_with_entities.sql` приводит исходную схему в соответствие с текущими JPA-сущностями.

## Настройка PostgreSQL

Создай базу `Kforum_DB` либо поменяй переменную `DB_URL`. По умолчанию приложение использует настройки подключения из исходного проекта; переменная `DB_PASSWORD` переопределяет локальный пароль. При необходимости задай переменные окружения:

- `DB_URL` — например `jdbc:postgresql://localhost:5432/Kforum_DB`
- `DB_USERNAME` — пользователь PostgreSQL
- `DB_PASSWORD` — пароль PostgreSQL
- `JWT_SECRET` — приватный секрет для JWT длиной не менее 32 байт

Не используй встроенный локальный JWT-секрет в развёрнутом приложении. Если база содержит историю Flyway, не меняй старую миграцию `V1`; изменения выполняются новой миграцией `V2`.

## Первый запуск

1. Настрой PostgreSQL и переменные окружения.
2. Запусти приложение из IntelliJ IDEA либо командой `mvn spring-boot:run` из каталога проекта.
3. Открой `http://localhost:8080/register`, создай обычный аккаунт и затем войди.
4. Чтобы выдать своему аккаунту роль администратора, выполни в PostgreSQL, указав свой email:

   ```sql
   UPDATE users SET role = 'ADMIN' WHERE email = 'your-email@example.com';
   ```

5. Выйди и войди снова, чтобы новая роль попала в текущую сессию. После этого появится пункт «Админ-панель», где можно управлять категориями.

Перед первым запуском обновлённого проекта сделай резервную копию `Kforum_DB`. Flyway применит миграцию `V2`; для уже существующей базы включён baseline на версии `1`, чтобы не пытаться повторно создать таблицы из `V1`.

## Маршруты

- `/` — главная и последние темы
- `/categories` — категории
- `/categories/{id}` — темы категории
- `/topics/{id}` — тема и комментарии
- `/topics/new` — форма создания темы, требует входа
- `/login`, `/register` — авторизация
- `/admin` — управление категориями, только администратор

Сборку Maven в текущем окружении проверить не удалось: Maven Wrapper не смог скачать дистрибутив с Maven Central из-за сетевой ошибки. Проверь сборку локально после загрузки зависимостей.
